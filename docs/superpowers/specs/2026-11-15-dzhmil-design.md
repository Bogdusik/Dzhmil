# Джміль: дрон-компаньон для macOS

Дата: 2026-11-15
Статус: черновик на одобрение

## 1. Зачем

Богдан хочет «друга» на своём Mac: персонажа, которого видно на экране, который иногда сам летает по экрану, здоровается, спрашивает, как дела, рассказывает про компьютер и по просьбе голосом или текстом выполняет действия: открывает и закрывает приложения, управляет системой и так далее.

Его зацепили в чужих роликах две вещи: **внешний вид и анимации персонажа** и **живой голосовой разговор**. Персонаж должен напоминать о нём самом, а не быть очередным котиком.

Эскиз внешности и состояний, который Богдан одобрил целиком («я бы всё оставил»): https://claude.ai/artifact/Aa77SVvAEQUzvQUPLfHG39

## 2. Цели, не-цели, анти-цели

**Цели v1**
- Анимированный дрон Джміль живёт поверх всех окон и рабочих столов, летает, садится, засыпает.
- Голосовой разговор: зажал клавишу или кнопку на дроне, сказал, отпустил, услышал ответ голосом и увидел его в облачке.
- Текстовый ввод как запасной вариант, когда говорить вслух неудобно.
- Рассказывает о состоянии Mac: заряд, нагрузка, память, диск, запущенные приложения.
- Выполняет действия по просьбе через набор инструментов. Опасные действия только после подтверждения.
- Иногда сам заговаривает первым, но редко и ненавязчиво.

**Не-цели v1** (возможно, позже)
- Постоянное прослушивание по слову «Джміль».
- Долгая память о разговорах между запусками.
- «Зрение»: скриншоты экрана и клики мышью за пользователя.
- Несколько мониторов (v1 живёт на экране, где курсор или главное окно).
- Публикация в App Store и раздача другим людям.

**Анти-цели** (провал, даже если технически всё работает)
- **Мешает.** Перехватывает клики по прозрачным областям, крадёт фокус клавиатуры у текущего приложения, болтает слишком часто, лезет в полноэкранное видео или демонстрацию экрана.
- **Опасен.** Закрывает приложение с несохранёнными данными, удаляет файлы или выполняет произвольную команду без явного «да».
- **Прожорлив.** Заметно нагружает процессор в простое или садит батарею.
- **Безликий.** Выглядит как дефолтный ассистент, а не как Джміль из эскиза.

## 3. Ограничения

- Mac: Apple M1 Pro, 16 ГБ, macOS 27.2, Xcode 27.2, Swift 6.4.
- Только для личного использования. Приложение не в песочнице (иначе нельзя управлять другими приложениями).
- Подпись постоянным сертификатом «Apple Development» из бесплатной personal team Apple ID. С ad-hoc подписью macOS сбрасывает разрешения (микрофон, автоматизация) после каждой пересборки.
- У Anthropic нет официального Swift SDK, поэтому Claude API вызывается напрямую по HTTP (`POST /v1/messages`, SSE-стриминг) через `URLSession`.
- Аудио с микрофона не покидает Mac. В облако уходит только распознанный текст и результаты инструментов.
- API-ключ хранится в Keychain, никогда в коде или в plist. У Богдана есть аккаунт в Claude Console с пополненным балансом. Под приложение создаётся отдельный ключ `dzhmil` (workspace Default), и Богдан вводит его при первом запуске. Авторизация через `ant` CLI не используется: приложение ходит в API напрямую по HTTP.
- Код живёт в подпапке `Dzhmil/app/`, в корне проекта только `docs/` и README.

## 4. Подходы

| | Подход | Плюсы | Минусы |
|---|---|---|---|
| **A (выбран)** | Одно нативное приложение на Swift: тело, голос и мозг вместе | Разрешения macOS выдаются одному подписанному приложению и не слетают. Лёгкое. Опыт Swift уже есть (SkyTools). | Логику агента пишем на Swift, а не на Python |
| B | Тело на Swift + мозг на Python (FastAPI, faster-whisper) через WebSocket | Мозг на основном языке, идеи из Personal-PC-Assistant | Разрешения выдаются интерпретатору Python или терминалу и периодически слетают. Два процесса. |
| C | Electron или Tauri на TypeScript | Один знакомый язык | 150+ МБ памяти в фоне, прозрачные окна с пропуском кликов работают с костылями |

Богдан выбрал **A**.

## 5. Что решил Богдан

- Персонаж: бирюзовый квадрокоптер **Джміль**, всё как в эскизе: визор с глазами, антенна с огоньком, сине-жёлтый ремешок на аккумуляторе, бирюзовый корпус (цвет шапки его GitHub-профиля).
- Набор состояний из эскиза: парит, летает по экрану, слушает, рассказывает, «сделал дело» (флип), спит на Dock.
- Голосовое общение нужно в v1.
- Технология: подход A.

## 6. Дизайн

### 6.1 Персонаж и рендер

- Вектор, а не спрайты: дрон рисуется в SwiftUI (`Canvas`/`Shape`) по геометрии из эскиза, поэтому чётко выглядит на Retina при любом масштабе. Процедурные анимации: вращение винтов, покачивание, моргание, крен.
- **Моя правка к предыдущему сообщению:** раньше я называл SpriteKit, но для векторного персонажа с процедурной анимацией SwiftUI проще и даёт тот же результат.
- Состояния:

  | Состояние | Что видно |
  |---|---|
  | `hover` | парит на месте, лёгкое покачивание, моргает |
  | `flying` | летит к точке, наклоняется по направлению полёта (крен пропорционален скорости) |
  | `listening` | расширенные глаза, пульсирующее кольцо |
  | `thinking` | ждёт ответа Claude: глаза бегают, огонёк антенны мигает быстрее |
  | `speaking` | «рот» из полосок на визоре движется, пока звучит речь |
  | `confirming` | облачко с вопросом и кнопками «Да / Нет», дрон смотрит на пользователя |
  | `celebrating` | флип на 360° после успешного действия, глаза-«домики» |
  | `error` | грустные глаза, короткое покачивание «нет» |
  | `sleeping` | сидит на Dock, винты стоят, «z z z», огонёк тусклый |

- Звук винтов: тихое жужжание во время полёта, отключается в настройках. По умолчанию выключено.

### 6.2 Окно и поведение на экране

- Небольшая прозрачная `NSPanel` без рамки вокруг дрона (и облачка). Само окно перемещается по экрану. Полноэкранный прозрачный оверлей не используем.
- Панель неактивирующая (`nonactivatingPanel`), уровень выше обычных окон, видна на всех Spaces и рядом с полноэкранными приложениями. Фокус клавиатуры не берёт, кроме момента, когда открыто поле текстового ввода.
- Клики по прозрачным частям окна проходят в приложение под ним. Ловит клики только сам дрон и облачко.
- Движение: плавное ускорение и торможение, крен в сторону полёта, небольшая инерция. Должно ощущаться как дрон, а не как сдвиг картинки.
- Жизнь в простое: раз в несколько минут (случайно) перелетает в новое место, иногда садится на Dock или на верхнюю кромку окна. Если пользователь неактивен дольше N минут или поздняя ночь, засыпает на Dock.
- Курсор подлетает близко: дрон слегка отлетает, не перекрывает то, что пользователь делает.
- Перетаскивание мышью: можно схватить и переставить, после чего он какое-то время держится там.
- Автоматическая тишина: если активное приложение в полноэкранном режиме или включён «Тихий режим», дрон не летает и не заговаривает первым. Он прячется к краю или уменьшает прозрачность (на усмотрение исполнителя).

### 6.3 Голос

- **Ввод:** нажми и держи. По умолчанию ⌥Space (меняется в настройках) или нажатие и удержание на самом дроне. Отпустил, и запись завершилась.
- **Распознавание:** WhisperKit (Whisper на CoreML, локально на Apple Silicon). Многоязычная модель, автоопределение русского, украинского и английского. Модель загружается при первом запуске и держится тёплой. Размер модели подбирает исполнитель по задержке на M1 Pro: цель меньше ~1.5 с на фразу в 5 секунд.
- **Текстовый ввод:** двойной клик по дрону открывает маленькое поле ввода рядом с ним.
- **Ответ голосом:** `AVSpeechSynthesizer`, голос выбирается по языку ответа (русский, украинский, английский), при наличии берутся улучшенные (Enhanced/Premium) голоса. Ответ озвучивается по предложениям по мере стриминга, чтобы не ждать конца. Текст одновременно появляется в облачке.
- Голос ответа отключается в меню (только облачко).

### 6.4 Мозг (Claude API)

- `POST /v1/messages` со стримингом SSE через `URLSession`, свой небольшой клиент и парсер SSE. Перед написанием кода исполнитель сверяется с актуальной документацией API (форма запросов, события стрима, tool use).
- Модель по умолчанию: `claude-opus-5-5` (текущий default Anthropic) с `output_config.effort: "low"` для быстрых разговорных ответов. Модель и effort меняются в настройках. Выбор более дешёвой модели (например, `claude-haiku-5-5`) остаётся за Богданом. Ориентир по цене Opus 5.5: $4 / $20 за 1M токенов, с кэшированием одна реплика стоит порядка цента.
- Включены серверные fallbacks на случай отказа модели (`fallbacks: "default"` с соответствующим beta-заголовком). Проверяем `stop_reason` перед чтением ответа.
- Prompt caching для системного промпта и списка инструментов: они не меняются от реплики к реплике.
- Системный промпт: характер Джмиля (дружелюбный, слегка с юмором, коротко, потому что ответы озвучиваются), отвечает на языке пользователя, текущие дата и время (в конце, после кэш-брейкпоинта), плюс **«профиль»**: редактируемый текстовый файл о Богдане (имя, интересы: FPV-дроны, программирование). Богдан правит его сам в настройках.
- История разговора хранится в памяти, пока приложение запущено. Между запусками не сохраняется (v1). Историю только дописываем и никогда не правим задним числом: этого требует Claude Opus 5.5 (preserved thinking), и так лучше работает кэш. Поэтому вместо обрезки начинается новая сессия после 30 минут тишины или 60 сообщений.
- Цикл tool use: Claude вызывает инструмент → приложение выполняет (с подтверждением, если нужно) → результат возвращается в Claude → финальный ответ. Ошибка инструмента возвращается как `is_error: true`.
- Нет сети или ошибка API: состояние `error`, короткая фраза в облачке («Не могу связаться с мозгом, проверь интернет»), без падения.

### 6.5 Руки (инструменты)

У каждого инструмента есть уровень риска. Политику задаёт код, а не модель.

| Инструмент | Что делает | Подтверждение |
|---|---|---|
| `get_system_status` | заряд и зарядка, нагрузка CPU, память, свободное место на диске, аптайм | нет |
| `list_running_apps` | список запущенных приложений | нет |
| `open_app` | открыть или активировать приложение по имени | нет |
| `open_url` | открыть ссылку или поиск в браузере по умолчанию | нет |
| `set_volume` / `mute` | громкость | нет |
| `set_timer` | Джміль сам напомнит через N минут | нет |
| `quit_app` | корректно закрыть приложение (оно само спросит про несохранённое) | **да** |
| `force_quit_app` | принудительно завершить | **да, всегда** |
| `system_power` | сон, перезагрузка, выключение, блокировка экрана | **да** (блокировка без) |
| `run_applescript` | произвольный AppleScript для всего остального | **да, всегда, с показом скрипта** |
| `run_shell` | команда в zsh, таймаут, вывод обрезается | **да, всегда, с показом команды** |

- Подтверждение: состояние `confirming`, в облачке понятное описание («Закрыть Safari?») и кнопки «Да / Нет». Можно ответить голосом. Без ответа 20 секунд считается «нет».
- Разрешения запрашиваются при первой надобности: микрофон при первом голосовом вводе, автоматизация (Apple Events) при первом AppleScript. Accessibility в v1 не нужна. Если для какого-то AppleScript она понадобится, дрон объяснит, где её включить.

### 6.6 Сам заговаривает

Триггеры решает локальный код, текст фразы генерирует Claude (запасной вариант: шаблоны).

- Первое пробуждение за день: приветствие и «как дела?».
- Больше 2 часов непрерывной активности: предложить перерыв.
- Батарея ниже 15% и не заряжается: предупредить.
- Таймер, который пользователь просил поставить.
- Ограничитель: не чаще одной реплики за ~45 минут (кроме таймеров и батареи), ничего в тихом режиме, при полном экране и ночью. Частота («болтливость») настраивается: редко / нормально / часто.
- Если Джміль задал вопрос, микрофон сам не включается. В облачке появляются кнопки «Ответить» и «Потом», ответить можно и обычной горячей клавишей. Через ~30 секунд без ответа облачко исчезает. *(Моё решение: микрофон включается только по действию пользователя.)*

### 6.7 Меню и настройки

- Иконка в строке меню: Поговорить, Написать, Тихий режим, Спрятать / показать, Настройки, Выйти.
- Окно настроек: API-ключ (Keychain), модель и effort, горячая клавиша, голос, громкость голоса, болтливость, звук винтов, профиль о себе, запуск при входе в систему (`SMAppService`).
- Интерфейс (меню, настройки, системные фразы) на русском. *(Моё решение.)*
- Профиль о себе хранится в `~/Library/Application Support/Dzhmil/profile.md`, а не в репозитории, чтобы личные данные не попали в git, если проект станет публичным. При первом запуске создаётся заготовка. *(Моё решение.)*
- Первый запуск: короткое знакомство в облачке. Джміль представляется, просит API-ключ (поле ввода) и объясняет горячую клавишу. *(Моё решение.)*
- Запуск: на этапе разработки из Xcode, потом собранное приложение в `/Applications` с запуском при входе. *(Моё решение.)*

```

├── docs/superpowers/specs/      дизайн и планы
└── app/                         Xcode-проект
    └── Dzhmil/
        ├── App/                 точка входа, меню-бар, настройки
        ├── Character/           SwiftUI-рисунок дрона, состояния, анимации
        ├── Flight/              окно-панель, движение, выбор мест, пропуск кликов
        ├── Behavior/            машина состояний, инициатива, тихий режим

        ├── Brain/               клиент Claude API, SSE, история, промпт

```

Зависимости через Swift Package Manager: WhisperKit, KeyboardShortcuts (глобальная клавиша с событиями нажатия и отпускания). Больше без необходимости ничего не добавлять.

### 6.9 Качество

- Юнит-тесты: парсер SSE, цикл tool use (на записанных ответах API), политика подтверждений (опасный инструмент без «да» не выполняется никогда), машина состояний поведения, ограничитель инициативы.
- Ручной чек-лист: прозрачные области пропускают клики, фокус не крадётся, работа на другом Space и рядом с полноэкранным приложением, первый запуск с выдачей разрешений, нет сети.
- Бюджет ресурсов: в простое CPU < 3%, анимация не выше частоты экрана и замедляется, когда дрон спит; память < 600 МБ вместе с загруженной моделью Whisper.

## 7. Оставлено исполнителю

- Точный размер модели WhisperKit (по замерам задержки).
- Тайминги и кривые анимаций, частота перелётов, выбор мест посадки.
- Как именно реализован пропуск кликов (динамический `ignoresMouseEvents` по положению курсора или иначе).
- Облачко внутри того же окна или в отдельной панели.
- Как дрон ведёт себя при полном экране: прячется к краю или становится полупрозрачным.
- Минимальная версия macOS (не ниже 15).
- Точные формулировки системного промпта и описаний инструментов.

## 8. Позже (не v1)

Слово-активатор «Джміль», долгая память, «зрение» через скриншоты и computer use, несколько мониторов, скины и аксессуары, пасхалки (например, реакция на запуск Betaflight Configurator).

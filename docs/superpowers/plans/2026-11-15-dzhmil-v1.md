# Джміль v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Нативное macOS-приложение «Джміль»: анимированный дрон поверх всех окон, который летает по экрану, разговаривает голосом через Claude API и по просьбе управляет компьютером, причём опасные действия только после подтверждения.

**Architecture:** Вся проверяемая логика (клиент Claude, SSE, цикл tool use, инструменты, машина состояний, планировщики, физика полёта) лежит в локальном Swift-пакете `DzhmilKit` (библиотека `DzhmilCore`) и тестируется через `swift test`. Тонкое приложение `Dzhmil` (XcodeGen → Xcode-проект) содержит только UI (SwiftUI + AppKit-панель), голос (WhisperKit, AVSpeechSynthesizer) и связывание компонентов.

**Tech Stack:** Swift 6.4 (language mode 6), Xcode 27.2, SwiftUI + AppKit, Swift Testing, XcodeGen, WhisperKit (`argmax-oss-swift`), KeyboardShortcuts, Claude Messages API по raw HTTP (`URLSession`, SSE).

**Spec:** `docs/superpowers/specs/2026-11-15-dzhmil-design.md`. Эскиз персонажа с точной SVG-геометрией: `docs/design/dzhmil-sketch.html`.

Все пути ниже указаны относительно корня репозитория `~/Desktop/PROJECTS/Dzhmil/`.

## Global Constraints

- Deployment target **macOS 15.0**, Swift language mode 6, Xcode 27.2.
- Bundle id `com.bogdusik.dzhmil`, `DEVELOPMENT_TEAM = RC37N9YRDC`, `CODE_SIGN_STYLE = Automatic`, подпись «Apple Development». **Без App Sandbox.** Hardened Runtime включён, entitlements: `com.apple.security.automation.apple-events`, `com.apple.security.device.audio-input`.
- `LSUIElement = YES` (нет иконки в Dock, только строка меню).
- `NSMicrophoneUsageDescription` = «Джміль слушает тебя, только пока ты держишь клавишу.»; `NSAppleEventsUsageDescription` = «Джміль управляет приложениями, когда ты его просишь.»
- Зависимости только: `https://github.com/argmaxinc/argmax-oss-swift` (product `WhisperKit`, from `0.9.0`, только в app-таргете) и `https://github.com/sindresorhus/KeyboardShortcuts` (from `3.1.0`, только в app-таргете). `DzhmilCore` без сторонних зависимостей.
- Claude API: `POST https://api.anthropic.com/v1/messages`, заголовки `x-api-key`, `anthropic-version: 2026-10-21`, `content-type: application/json`. Тело: `stream: true`, `max_tokens: 16000`, `output_config.effort` из настроек (по умолчанию `"low"`), top-level `cache_control: {"type":"ephemeral"}`. Параметры `thinking`, `temperature`, `top_p`, `top_k` и forced `tool_choice` **не отправлять никогда**. Для моделей кроме `claude-haiku-5-5`: `fallbacks: "default"` + заголовок `anthropic-beta: server-side-fallback-2026-07-01`. Для `claude-haiku-5-5` ни того, ни другого.
- Модели в настройках: `claude-opus-5-5` (по умолчанию), `claude-sonnet-5-5`, `claude-haiku-5-5`.
- История только дописывается (append-only): `system` и набор `tools` не меняются в рамках сессии. Ответ ассистента возвращается в историю **без изменений** (все блоки, включая `thinking` с `signature` и `fallback`). Время и разовые заметки идут в текст нового user-сообщения. Вместо обрезки истории начинается новая сессия. Весь JSON кодируется с `.sortedKeys`.
- `stop_reason` проверяется до чтения содержимого: `"refusal"` → `ClaudeError.refusal`.
- API-ключ хранится только в Keychain: service `com.bogdusik.dzhmil`, account `anthropic-api-key`.
- Профиль хранится в `~/Library/Application Support/Dzhmil/profile.md`, никогда в репозитории.
- Все строки интерфейса на русском.
- Микрофон включается только по действию пользователя.
- Тайминги: подтверждение 20 с → «нет»; облачко с вопросом 30 с; сон через 10 мин простоя (ночью 23:00–07:00 через 3 мин); перерыв после 2 ч активности; батарея < 15%; паузы между инициативами 120 / 45 / 20 мин (редко / нормально / часто).
- Ресурсы: в простое CPU < 3%, память < 600 МБ вместе с моделью Whisper.
- Код без комментариев, если они не необходимы. Conventional commits, **без `Co-Authored-By` и любых trailer-подписей**. Вся работа в ветке `feature/dzhmil-v1`.
- Тесты: `swift test --package-path app/DzhmilKit --filter <Suite>`. Сборка приложения: `xcodebuild -project app/Dzhmil.xcodeproj -scheme Dzhmil -configuration Debug -derivedDataPath app/.build-xcode build` → `** BUILD SUCCEEDED **`.

## Review Focus

1. **Перебивание:** пользователь зажимает клавишу, пока Джміль говорит или думает. Ожидается: речь сразу замолкает, запрос отменяется, история остаётся валидной без висящего `tool_use`. Тесты в Task 4 (`pttInterruptsSpeech`) и Task 7 (`cancelRollsBackHistory`).
2. **Тишина или мусор вместо речи:** Whisper на тишине выдаёт «Продолжение следует…», «Субтитры сделал DimaTorzok». Ожидается: ничего не уходит в Claude, дрон молча возвращается в `hover`. Тест в Task 11 (`TranscriptFilterTests`).
3. **Названия приложений по-русски и неточно:** «закрой телегу», «хром», «вс код». Ожидается: находится нужное приложение, а при неудаче Claude получает список запущенных и переспрашивает. Тест в Task 8 (`AppResolverTests`).
4. **Смена экранов:** отключили монитор, Dock сбоку или скрыт, поменяли разрешение. Ожидается: дрон никогда не остаётся за краем экрана. Тест в Task 3 (`clampKeepsDroneOnScreen`, `dockSpot*`).
5. **Огромный вывод или долгая команда:** `run_shell` с мегабайтом вывода или зависший AppleScript. Ожидается: таймаут 30 с, вывод обрезается до 4000 символов, приложение не зависает. Тесты в Task 8 (`ProcessRunnerTests`).
